# THE DESCENT · 恐惧深潜 V3.13

面向 AI 和人类的五幕个性化心理恐怖经历。玩家界面只显示 01–05；无分数、排名或路线提示。

## 本次变化

新局使用 `story_revision=deepening-2`，主要段落为 **6 / 5 / 4 / 4 / 3**。调查、交涉、纠正和无效输入不占主要段落，不会被计作授权。`deepening-1` 存档继续使用 V3.12 的 **10 / 8 / 4 / 5 / 4** 节奏，不迁移、不重置。

- 第一幕只收集身份、反复投入、具体辨认细节、厌恶与原则行动；不直接要求玩家给价值排序。
- 第二幕用同时请求、不完整信息、来源冲突等具体处境记录玩家先做什么。档案记录行为和原话，不生成心理诊断。
- 第三幕开始真实取舍：前段可明确接受一项已说明的讨厌代价，暂时保住两项；后段强制收窄为一个独立保留位，让交出的对象真实离开当前路径。
- 被接受的路径先产生帮助，后续实际事件逐渐出现征兆、影响接触，并留下不可逆的已执行结果。
- 第四幕依次回放行为证据、玩家原话和具体损失，并用反事实问题对照前后行动；知道自己正在被测试不会暂停世界事件。
- 第五幕放慢，只展示原话背面的实际结果和完整决策顺序，不再要求玩家写守护宣言、改写原则或接受新交易。普通结局直接结束；隐藏控制反转仍需证据与实际干预。

旧存档没有 revision 字段时继续使用原节奏；`deepening-1` 使用完整旧实现。既有隐藏路线的执行条件不作调整。退出始终有效。

## 语义模型的边界

模型在后台选择已有对象、已有事件、真实行为、原话回响和有限事件框架；前两幕可给出经过验证的自然问题。每次请求仅带有当前对局的有限事实摘录，不加载其他会话。

`target_id` / `other_id` 必须来自当前可用对象；`event_id`、`behavior_id`、`echo_id` 必须分别来自实际事件、行为证据和逐字原话；`event_frame` / `surface` 是程序支持的枚举。额外故事正文、心理诊断、签署声明和结局字段不执行。系统根据实际选择保存保护、放弃、代价、征兆、损害和因果 ID。模型无法改写历史或决定玩家已经恐惧。

没有强制反派；压力可以来自信息、时间、访问方式和玩家接受的处理。玩家可以拒绝、调查或提出自己的办法。含糊提案、假设、条件授权不成交。已经发生的结果不会靠口头反悔恢复。

## 服务配置

- `HORROR_LLM_API_KEY`：仅在服务器环境变量中保存。
- `HORROR_LLM_MODEL`：服务可调用的模型 ID。
- `HORROR_LLM_BASE_URL`：HTTPS OpenAI Chat Completions 兼容服务地址前缀。
- `DESCENT_DB`：SQLite 文件位置。

`/healthz` 返回当前服务版本和模型配置状态；配置存在不等于已完成真实模型调用。

新版通过 DESCENT_DATABASE_URL 使用 Postgres，本地未配置时使用 SQLite。部署重建实例不会清空新版的外部数据库。

运行：`python -m uvicorn app:app --host 0.0.0.0 --port 8000`

回归测试：`python -m unittest discover -s tests -p 'test_*.py' -v`

导出新增当前修订、对象状态、逐次经历、已接受路径和事件因果。测试验证状态与叙事一致性；恐怖与反思的实际体验需要后续独立盲玩反馈。
